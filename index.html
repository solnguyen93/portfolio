ChronoRoam

Chrono for time, roam for travel.

A trip planner built around your days. Map out every day down to the minute or keep it loose, even add a flight you haven't booked yet. Name each day, like "Disneyland Day" or "Jet Lag Rest Day", so you know what today's about at a glance.

Save things you want to do, eat or buy, then move them onto a day. Every day shows the weather for wherever you'll be, worked out automatically from your flights and hotels, so the beach day can dodge the rain.

Pack with one simple checklist or bag by bag, so when you land at 11pm you know exactly which suitcase has the toothbrush.

Forward a booking email and ChronoRoam fills in the details. Get tips for where you're headed, like whether you need a visa or a plug adapter. Plan on your computer with the calendar view, then take it with you on your iPhone.

  • React
  • Node.js
  • Express
  • PostgreSQL
  • Claude & OpenAI

How it's built
  • React web app wrapped with Capacitor to ship the same code as a native iOS app
  • Node.js/Express REST API on Render with PostgreSQL through raw SQL (pg)
  • Inbound email: a Cloudflare Email Worker parses the MIME message and posts it to a secret-authenticated webhook
  • AI extraction runs on a low-cost model first, with deterministic checks for corrupted or incomplete output and a fallback to Claude
  • Rank-based location inference for accurate per-day weather: flight arrival > transit or directions > hotel > activity location, then carry-forward from the previous day, then first departure airport > trip destinations > place name in the trip title; late arrivals count from the next day, and geocoder matches more than 500 km from higher-ranked signals are rejected
  • Trip titles are matched against an offline set of ~1,750 place names before a single geocoding call, so unresolvable titles cost no network requests
  • Custom pointer-event drag and drop: long-press reordering with a drop-preview line, an edge auto-scroll loop, and background polling paused mid-drag
  • Destination tips and flight, geocoding and weather lookups are cached server-side and shared across users
  • Payments through Stripe (web) and Apple In-App Purchase (iOS), both verified on the server before unlocking
  • Membership-based access, guest accounts that merge into a real account on sign-in, and free-trial abuse prevention by email and device ID

VigilKura

A web app for parents that listens during a child's screen time, shows a live transcript, and alerts you with a sound and an email when it hears a word on your list. Set a word list and time limit for each child, look back at what was said, and translate transcripts into your language. Works best in Chrome or Safari.

How it's built
  • React and Material UI frontend; speech is turned into text by the browser's built-in Web Speech API (Chrome or Safari)
  • Node.js/Express API on Render with a Neon PostgreSQL database
  • Speech-to-text runs in the browser, so the API only ever receives text and no audio is stored
  • Email goes through the Gmail API over HTTPS with a send-only OAuth scope, since Render's free tier blocks SMTP; alerts are rate-limited per child
  • Uses pagehide and navigator.sendBeacon to detect the tab closing, with a 30-second server-side grace period to tell a reload from a real exit
  • Transcripts are translated with OpenAI in batches of 40 lines using JSON output, and each batch is checked line for line so the translation stays aligned with the original

TripCheck

A packing checklist where you can put items inside other items, like a toiletry bag inside a suitcase, so your list is easier to organize and search than a notes app.

How it's built
  • React and Material UI frontend; Node.js/Express REST API with PostgreSQL
  • Nested items are stored as an adjacency list (parent_item_id) and rebuilt into a tree recursively; deletes cascade recursively through descendants
  • bcrypt password hashing and JWT auth; a user_checklists join table with owner/shared roles controls who can edit, share or delete
  • Integrates the Visual Crossing, ExchangeRate-API and Restful Countries APIs

FlightCast

A flight search app that shows flight options and prices alongside the weather forecast for your destination, all in one place.

How it's built
  • Python and Flask app with server-rendered Jinja pages and vanilla JavaScript
  • Flight offers from the Amadeus API; the server handles the OAuth client-credentials token so secrets stay off the client
  • Visual Crossing for destination forecasts and ExchangeRate-API to convert EUR fares
  • PostgreSQL via Flask-SQLAlchemy models; session-based auth with bcrypt hashing and CSRF-protected Flask-WTF forms
